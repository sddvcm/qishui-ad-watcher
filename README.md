# 🎧 汽水音乐自动看广告（qishui-ad-watcher）

自动观看「汽水音乐」App 福利中心的广告，自动领取免费听歌时长。
通过 **手机投屏 + OCR 识别 + 模拟点击** 实现，无需手机安装任何程序、无需 ADB。

## ✨ 功能特性

- 自动点击「领时长 / 继续领」入口按钮，打开视频或直播广告
- **视频广告**：等待倒计时结束 → 自动关闭 → 点击「领取奖励」→ 自动进入下一广告
- **直播广告**：5 秒倒计时内自动点击「取消」，避免误入直播间
- **直播间容错**：万一进入直播间，自动定位右上角 X 退出，并处理「退出不看了」推荐弹窗
- 自动处理「坚持退出」免费解锁弹窗（点击「继续观看 / 领取奖励」继续）
- 可设置广告数量上限，到达后自动停止
- 内置 GUI 控制面板：可视化配置所有参数 + 实时日志 + 统计
- 调试模式：保存带 OCR 标注和点击位置的截图，便于排查

## 📦 快速开始

Windows 10/11 64 位，**无需安装 Python**，下载发布包即可使用。

1. 手机安装 **vivo 办公套件**，用数据线/USB 把手机投屏到电脑
2. 手机上打开「汽水音乐」→ 福利中心 → 看广告领时长页面
3. **下载发布包**：[Releases 页面](https://github.com/sddvcm/qishui-ad-watcher/releases) 下载最新的 `dist.zip`
4. 解压 zip，双击文件夹里的 **`汽水音乐自动看广告.exe`**
5. 在控制面板确认「窗口标题关键词」为 `投屏`，点击「开始运行」

> 提示：脚本会自动锁定标题含「投屏」的最大窗口（即手机投屏窗口），并自动跳过本程序窗口。

## 🖥 从源码运行

```bash
pip install -r requirements.txt
python qishui_gui.py        # GUI 控制面板
# 或
python qishui_ad_watcher.py # 命令行版
```

### 命令行参数（qishui_ad_watcher.py）

| 参数 | 作用 |
|:---|:---|
| `--window <关键词>` | 指定投屏窗口标题关键词 |
| `--interval <秒>` | 设置扫描间隔 |
| `--max-ads <n>` | 广告数量上限（0=无限） |
| `--debug` / `--no-debug` | 开关调试截图 |
| `--dry-run` | 试运行：只检测不点击 |
| `--test` | 测试模式：截图 + OCR 后退出 |
| `--list-windows` | 列出当前可见窗口 |

## 🔧 GUI 配置项

| 分组 | 参数 |
|:---|:---|
| 基本设置 | 窗口标题关键词、扫描间隔、广告数量上限、各类超时 |
| 视频广告点击位置 | 「领取成功」右侧 X 按钮偏移 |
| 直播广告点击位置 | 「取消」按钮偏移 |
| 直播间退出点击位置 | 观众数/关注右侧偏移、固定位置比例、退出超时 |
| 其他选项 | 保存调试截图、试运行模式 |

配置自动保存到 `gui_config.json`，下次启动自动加载。

## 🧱 技术原理

```
手机投屏窗口 → mss 截图 → RapidOCR 文字识别 → 状态机判断 → 模拟鼠标点击
```

- 截图：`mss`（投屏内容为视频流，`PrintWindow` 抓不到，必须屏幕区域截图）
- OCR：`rapidocr-onnxruntime`（本地离线、中文效果好）
- 点击：Win32 `SetCursorPos` + `mouse_event`
- GUI：`PyQt5`
